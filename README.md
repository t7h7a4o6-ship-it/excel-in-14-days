# Excel in 14 Days

A landing page for an online course. This is a **sample project** for a fictional course, built to show the kind of single-goal page I deliver for products, courses and events.

## What it shows
- One clear goal: collect sign-ups for a waiting list
- Sign-up form with client-side validation and accessible error messages (`aria-invalid`, `role="alert"`)
- FAQ built with native `<details>` elements, no JavaScript needed
- Responsive layout using CSS grid and flexbox
- Single file, no frameworks, fast to load

## Run it
Open `index.html` in any browser. No build step.

## Connect the form for a real client
The form currently shows a thank-you message and sends nothing. For a real project it can be connected to an email service or a form tool, so each sign-up reaches the client's inbox.

## Built with
HTML, CSS, vanilla JavaScript.
